## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/sourabhchetan/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Open `index.html` in your browser.

For development, you can also use **VS Code with Live Server**.
